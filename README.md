# Painel pessoal

App instalável (PWA) que mostra o dia da Isis: tarefas de hoje, contagem regressiva da ADP, bloco de estudos e os
próximos dias. Os dados vêm do Notion pessoal, gerados pelo agente em `/opt/data/profiles/pessoal/scripts/painel_dados.py`.

- Sem dado sensível: nada de dinheiro, documento ou senha.
- Página marcada com `noindex`, fora de buscadores.
- Para instalar no iPhone: abrir no Safari, Compartilhar, "Adicionar à Tela de Início".
